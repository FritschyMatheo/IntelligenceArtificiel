# TD2

Fix erreur images SVG sur windows : ``winget install tschoonj.GTKForWindows``

Lancer le TD2 (venv à la racine du dépôt `IntelligenceArtificiel`) :
```
python -m venv .venv

.\.venv\Scripts\Activate.ps1

pip install -r requirements.txt

python.exe -m pip install --upgrade pip

cd TD2

python main.py
```
