# TD3 - Minimax, Alpha-Beta & MCTS (Puissance 4)

Lancer le TD3 (venv à la racine du dépôt `IntelligenceArtificiel`) :
```
python -m venv .venv

.\.venv\Scripts\Activate.ps1

pip install -r TD3\requirements.txt

python.exe -m pip install --upgrade pip

cd TD3

python app.py
```
Puis ouvrir http://127.0.0.1:5000 dans le navigateur.

Benchmark des algorithmes (tableau + graphiques sauvegardés dans `benchmark.png`) :
```
python benchmark.py
```
